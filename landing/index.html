Iron Arachne is a web app for building worlds. If you’re a game master, a player, an author, or just someone who enjoys world-building, this app is for you.

The app is local-only. There are no accounts. Anything that can be saved is saved locally to your browser’s storage. There is no tracking of any kind. No advertising, and no affiliate links. This is built for humans to use and enjoy.

It’s built as an open-source project by Ben Overmyer. That’s me. If you have comments, questions, complaints, or other feedback, feel free to send it to ben@ironarachne.com, or if you’re on Mastodon, @skysong@floss.social.

Side note: none of the generators or tools use AI; it’s all procedural and deterministic.
