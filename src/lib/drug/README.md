# Drug

This library generates a **drug**: what it is, how it is taken, what it does, how strong it is, how
long it lasts, what it costs the user afterwards, and how easy it is to find. It is used for
science-fiction and modern settings where the party's contraband needs a name and a description
rather than a rules block.

## Features

- **`Drug`** — `name`, `description`, `drugType`, `method` (how it is administered), `effectType`
  and `effectDescription`, `strength`, `color`, `duration`, `sideEffect`, and `commonality`.
- **`generate`** — build a drug from a `DrugGeneratorConfig` and an `RNG`; `getDefaultConfig`
  allows every type.
- **Data tables** — `drugTypes.all()` and `effectTypes.all()`, namespaced rather than starred
  because both export `all`.

## Usage

```typescript
import { generate, getDefaultConfig } from '$lib/drug';

const drug = generate(getDefaultConfig(), rng);

drug.name;
drug.sideEffect;
```

Restrict what may be generated by narrowing the config's tables:

```typescript
import { drugTypes, effectTypes, generate, getDefaultConfig } from '$lib/drug';

const config = getDefaultConfig();
config.effectTypes = effectTypes.all().filter((effect) => effect.name === 'stimulant');

const stimulant = generate(config, rng);
```

The generator takes an existing `RNG` rather than a seed, because it is normally called as part of a
larger run that already owns one.
