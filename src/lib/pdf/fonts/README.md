[`google/fonts` at e44c4b011a820c2cbe2fd2cfa8052037d7edb571](https://github.com/google/fonts/tree/e44c4b011a820c2cbe2fd2cfa8052037d7edb571/ofl/crimsontext).

inside generated project PDFs. They are separate from the repository's web fonts, which are
vendored from the Iron Arachne branding repository.
