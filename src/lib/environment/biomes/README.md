# Biomes

This library handles the generation and classification of biomes. A biome represents a large naturally occurring community of flora and fauna occupying a major habitat. In this system, biomes are classified using temperature, humidity, altitude, and aquatic features.

## Files

- `biomes.ts`: Contains the main generator function (`generate`) and other functions relating to assembling biomes and computing their traits (features, descriptions).
- `biome_classifications.ts`: Definitions of the exact classifications (e.g. "deciduous forest", "desert") and their stat ranges.
- `biome_types.ts`: TypeScript definition forms for data structures used by the biome generation library.
- `index.ts`: The main entry point to load functions or types for biomes.
