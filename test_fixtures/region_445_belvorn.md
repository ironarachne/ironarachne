`region_445_belvorn.json.gz` is the unmodified JSON output of
`rollRegionSnapshot('5wyedz5q272fz')` with default options at commit `1ffabf08` (payload version 14).
It was captured by running that revision in an isolated temporary checkout with the workspace's
installed dependencies. Gzip uses a zero timestamp; decompression recovers the exact captured JSON.
The fixture contains The Woods of Belvorn and eight settlements, including Revilun. It is not a
snapshot generated by the current implementation under a historical label.

The editorial regression test migrates the payload without rerolling, then checks the new plan's
support for Revilun's road hub and relative size, woodland, diamond/copper opportunities and owlbear
presence. Source facts and their old wording must remain unchanged. Other tests use current
seeded generation or explicit small domain fixtures.
